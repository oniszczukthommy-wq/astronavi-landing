# 天文通 · 官网落地页（Astronavi Landing）

单文件自包含 HTML 的深色星空电影风产品宣传页。Three.js r149 星空背景 + GSAP 3.12 滚动叙事，无构建依赖。

## 技术栈
- Three.js r149（分层视差星野、流星、太阳系、月相）
- GSAP 3.12 + ScrollTrigger
- 原生 JS，单文件，图片已 base64 内嵌
- Noto Serif SC 大标题 / Noto Sans SC 正文

## 本地运行
直接用浏览器打开 `index.html`，或 `python3 -m http.server 8000`。
